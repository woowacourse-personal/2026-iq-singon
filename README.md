# 🎤 Singon (싱온)

> 노래를 켜다, 함께 부르다. 헤드셋 하나로 접속하는 초저지연 온라인 노래방.

멀리 있는 친구·연인과 함께 노래방 감성으로 노래를 부를 수 있는 웹 서비스입니다.
서버를 거치지 않는 P2P(WebRTC) 음성 연결과 브라우저 오디오 이펙트(에코/딜레이)로
"코인노래방 마이크 잡은 느낌"을 재현합니다.

## ✨ 핵심 기능

- **초저지연 P2P 음성 연결** — PeerJS 기반 WebRTC 다이렉트 콜, 서버 경유 없음
- **노래방 에코 이펙터** — Web Audio API 딜레이 피드백 루프 (깊이/딜레이 실시간 조절)
- **유튜브 MR 동기화** — TJ/금영 공식 MR 영상을 임베드하고, 두 접속자의 재생 위치를 RTT 보정으로 자동 싱크
- **오리지널 곡 모드** — 저작권 프리 자체 반주(프로시저럴 신스) + 파트 구분 가사 엔진
- **초대 링크** — 링크 하나로 친구가 바로 방에 입장
- **검증 설문** — 프로토타입 피드백 수집 및 집계

## 🚀 로컬 실행

정적 웹앱이라 빌드 과정이 없습니다. 마이크 권한 때문에 반드시 `localhost`(secure context)로 띄워야 합니다.

```bash
python3 -m http.server 5173
# → http://localhost:5173 접속
```

혼자서 P2P를 테스트하려면 탭을 2개 열고, 한쪽의 방 ID를 다른 쪽 '친구 방 ID로 연결'에 입력하세요.

## 🏗️ 구조

```
├── index.html          # 마크업
├── css/style.css       # 네온 커스텀 스타일
└── js/
    ├── songs.js        # 저작권 프리 오리지널 곡 DB
    ├── audio.js        # Web Audio 파이프라인 (마이크/에코 FX/모니터링)
    ├── synth.js        # 프로시저럴 신스 반주 엔진
    ├── karaoke.js      # 재생 컨트롤러 + 유튜브 iframe 동기화 + 가사 엔진
    ├── peer.js         # PeerJS 연결, 데이터 프로토콜, RTT 측정
    ├── ui.js           # 채팅/비주얼라이저/이모트/모달/설문
    └── main.js         # 엔트리포인트
```

### 동기화 프로토콜 (유튜브 모드)

- 재생을 시작한 쪽이 **리더**가 되어 4초마다 현재 재생 위치를 브로드캐스트
- 수신 측은 5초 주기 ping/pong으로 측정한 **RTT/2**를 보정값으로 사용
- 드리프트가 **0.4초**를 넘으면 seek으로 위치 보정
- 반주는 각자 로컬(유튜브)에서 재생하고, 네트워크로는 목소리(Opus)만 전송
