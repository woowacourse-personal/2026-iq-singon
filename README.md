# 🎤 SINGON (싱온)

> 헤드셋 하나로 즐기는 온라인 듀엣 노래방

**👉 바로 써보기: https://singon.vercel.app**

멀리 있는 친구·연인과 함께 부르는 웹 노래방입니다. 서버를 거치지 않는 P2P(WebRTC)로 목소리를 연결하고,
브라우저에서 직접 노래방 에코를 걸고, 유튜브 MR을 서로 같은 위치로 동기화해 재생합니다.

## ✨ 핵심 기능

- **P2P 음성 연결** — PeerJS(WebRTC) 다이렉트 콜. 서버 경유가 없어 지연이 짧습니다
- **노래방 에코 이펙터** — Web Audio 딜레이 피드백 루프. 에코 깊이/딜레이/볼륨 실시간 조절
- **유튜브 MR 동기화** — RTT 보정 + 재생속도 미세조정(0.75x/1.25x)으로 끊김 없이 자동 싱크
- **관전석** — 듀엣 2인이 찬 뒤 들어온 친구는 자동으로 관전석에 배치. 같은 MR을 보고 싱어 목소리를 들으며 리액션으로 응원
- **오리지널 곡 모드** — 저작권 프리 자체 신스 반주(프로시저럴 드럼 그루브) + 파트 구분 가사 엔진
- **초대 링크** — 링크 하나 보내면 친구가 바로 입장

## 🎙️ 사용법

1. https://singon.vercel.app 접속 → 상단 **[초대 링크]** 를 복사해 친구에게 전송
2. 친구가 링크를 열고 **[마이크 켜고 입장하기]** 를 누르면 자동으로 듀엣 연결 (3번째 입장부터는 관전석)
3. 유튜브 MR 영상 주소를 붙여넣고 **[불러오기]** → **[노래 시작]** 을 누르면 함께 재생
4. 좌측 설정 패널에서 에코 깊이/딜레이, MR·친구 목소리 볼륨을 조절
5. 🎧 **이어폰/헤드폰 필수** — 스피커를 쓰면 하울링이 발생합니다

> ⚠️ TJ노래방 공식 MR은 권리사가 외부 사이트 재생을 차단해 사용할 수 없습니다.
> 금영(KY) 공식 MR은 곡에 따라 재생 가능하며, 임베드가 허용된 영상이면 무엇이든 동작합니다.

## 🚀 로컬 실행

정적 웹앱이라 빌드 과정이 없습니다. 마이크 권한 때문에 반드시 `localhost`(secure context)로 띄워야 합니다.

```bash
python3 -m http.server 5173
# → http://localhost:5173 접속
```

혼자서 P2P를 테스트하려면 탭을 2개 열고, 한쪽의 방 ID를 다른 쪽 '친구 방 ID로 연결'에 입력하세요.

## 🏗️ 구조

```
├── index.html          # 마크업
├── css/style.css       # 네온 커스텀 스타일
└── js/
    ├── songs.js        # 저작권 프리 오리지널 곡 DB
    ├── audio.js        # Web Audio 파이프라인 (마이크/에코 FX/모니터링)
    ├── synth.js        # 프로시저럴 신스 반주 + 드럼 킷
    ├── karaoke.js      # 재생 컨트롤러 + 유튜브 iframe 동기화 + 가사 엔진
    ├── peer.js         # PeerJS 연결, 데이터 프로토콜, 관전석, RTT 측정
    ├── ui.js           # 채팅/사이드 패널/비주얼라이저/이모트/모달
    └── main.js         # 엔트리포인트
```

### 동기화 프로토콜 (유튜브 모드)

- 재생을 시작한 쪽이 **리더**가 되어 2초마다 현재 재생 위치를 브로드캐스트
- 수신 측은 ping/pong으로 측정한 **RTT/2**를 보정값으로 사용
- 드리프트 0.08~0.6초는 **재생속도 미세조정**으로 끊김 없이 흡수, 그 이상만 시크
- 반주는 각자 로컬(유튜브)에서 재생하고, 네트워크로는 목소리(Opus)와 제어 메시지만 전송
- 관전자는 호스트가 상태를 릴레이(스타형), 싱어 음성은 단방향 콜로 수신
